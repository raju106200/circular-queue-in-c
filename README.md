# circular-queue-in-c
A menu-driven Circular Queue implementation in C using arrays, with enqueue, dequeue, and display operations. Demonstrates FIFO and circular queue concepts in Data Structures.

# Circular Queue in C

A simple menu-driven C program implementing a circular queue using an array.

## Operations
- Enqueue (Insert an element)
- Dequeue (Delete an element)
- Display queue elements
- Exit

## Concepts Used
- Arrays
- FIFO (First In, First Out)
- Circular Queue
- Functions
